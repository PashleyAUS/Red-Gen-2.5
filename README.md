# Red-Gen-2.5

A mod for Pokemon G/S on gen1recomp that recreates the story of Pokemon R/B with added Johto Post game and a few added mechanics from other Gen's. 

Currently the mod is in very early stages. (Up to and including Pewter City and events that take place there)
Please report any bugs or inconsistencies found! I would also love to hear any feedback or suggestions on what I should include in future updates.

Installation/ use

- Step 1. Download and install Gen1Recomp from here: https://github.com/bryanthaboi/gen1recomp
- Step 2. Import a dumped copy of you're Pokemon Gold cartridge as per instructions on Gen1recomp
- Step 3. Download latest release of Red-Gen 2.5 from here: https://github.com/PashleyAUS/Red-Gen-2.5/releases
- Step 4. Go to "mods" tab in Gen1recomp (looks like a puzzle piece), click on the "Import mod.zip" button and select the .zip file you just downloaded
